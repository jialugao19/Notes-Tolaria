# IP Reporter

定时采集 Linux 主机的内网及境内/境外公网 IPv4/IPv6，并在地址变化或心跳到期时通过 ServerChan 推送报告。

1. 用户级 crontab （属于某个 Linux 用户的定时任务表）每小时调用一次 ip-reporter。
2. 程序取得非阻塞文件锁，防止两个 ip-reporter 实例同时运行。
3. 从 YAML 或 .env 安全加载 ServerChan 接口和报告长度配置。
4. 通过 ip 获取并过滤宿主机内网 IPv4/IPv6。
5. 分别访问境内、境外探针，强制查询 IPv4/IPv6，并在主探针失败时使用备用源。
6. 将地址规范化，与上次成功推送的状态比较。
7. 首次运行、地址/健康状态变化、强制执行或满 24 小时时生成报告。
8. 通过 ServerChan 推送完整报告；只有推送成功后才原子更新状态文件。
9. 未变化时直接结束，失败时保留旧状态供下一小时重试。
